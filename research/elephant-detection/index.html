Real-Time Elephant Detection Using TinyML on ESP32

This research investigates the feasibility of deploying a lightweight Convolutional Neural Network for binary elephant classification on an ESP32 microcontroller using TensorFlow Lite for Microcontrollers — achieving real-time inference without cloud connectivity.

Abstract

Human-elephant conflict in South Asia causes significant economic loss and poses risks to both human life and elephant conservation. Automated detection systems capable of operating in remote, off-grid environments represent a practical approach to early warning. This paper presents the design, training, quantisation, and deployment of a lightweight binary image classifier for elephant detection on the ESP32 microcontroller. The model achieves 91.4% accuracy after INT8 post-training quantisation, with an inference time of 1.4 seconds and a memory footprint of 56 KB Flash and 142 KB SRAM — well within the constraints of the target device.

Introduction

The Sri Lankan elephant (Elephas maximus maximus) is an endangered subspecies that increasingly comes into conflict with human settlements as natural habitat shrinks. Farmers in border regions lose crops and property to elephant incursions, and retaliatory killings remain a persistent threat to the species.

Electric fences are the most widely deployed deterrent, but they are passive — they do not identify the cause of a breach or provide advance warning. A system capable of visually detecting elephant presence before physical fence contact would provide a meaningful improvement in response time and situational awareness.

Cloud-based computer vision systems require reliable internet connectivity, which is unavailable in most elephant habitats. TinyML — the practice of running trained machine learning models on microcontrollers — offers a viable alternative that operates entirely at the edge.

Background

TinyML and Edge Inference

TinyML has emerged as a significant research area following advances in model compression and the availability of optimised inference libraries such as TensorFlow Lite for Microcontrollers (TFLM). Warden and Situnayake (2019) demonstrated that CNN models compressed via quantisation can perform keyword spotting, gesture recognition, and image classification on ARM Cortex-M processors with as little as 256KB SRAM.

Quantisation

Post-training quantisation converts model weights from 32-bit floating-point (FP32) to 8-bit integers (INT8), reducing model size by approximately 4× and improving inference speed on hardware without floating-point acceleration units. The accuracy trade-off is typically less than 3% for classification tasks when a representative calibration dataset is used.

Depthwise Separable Convolutions

Howard et al. (2017) introduced MobileNets, demonstrating that replacing standard convolutions with depthwise separable convolutions reduces computation by a factor of 8–9× while maintaining comparable classification accuracy. This approach is applied in the model architecture presented here.

Methodology

Dataset Collection

The dataset consists of 4,600 images split equally between elephant and non-elephant classes. Elephant images were sourced from public wildlife datasets and camera trap repositories. Non-elephant background images were selected to represent the environments in which the system will be deployed — jungle edges, farmland boundaries, and open scrubland.

All images were resized to 96 × 96 pixels and converted to grayscale to match the ESP32-CAM OV2640 capture configuration and reduce model complexity.

Data Augmentation

  • Horizontal flip (p=0.5)
  • Random brightness adjustment (±25%)
  • Random contrast adjustment (±20%)
  • Random crop (±10% each axis)
  • Gaussian noise (σ = 0.02)

Evaluation Protocol

The dataset was split 80% / 20% for training and validation. Model accuracy was evaluated on the validation set before and after INT8 quantisation to quantify the accuracy degradation introduced by the compression step. Inference time was measured as the average of 100 consecutive inference runs on the physical ESP32 hardware.

Model Design

The model architecture was designed under a strict constraint: the total model size after INT8 quantisation must not exceed 100KB to remain safely within the 4MB Flash storage of the ESP32, leaving space for the firmware, camera drivers, and MQTT stack.

Quantisation and Optimisation

Post-training full integer quantisation was applied using the TensorFlow Lite Converter. A representative dataset of 200 images (100 per class) was provided to the converter to calibrate the per-layer activation scaling factors required for accurate INT8 inference.

Quantisation Configuration

converter = tf.lite.TFLiteConverter.from_keras_model(model)
converter.optimizations = [tf.lite.Optimize.DEFAULT]
converter.representative_dataset = representative_data_gen
converter.target_spec.supported_ops = [tf.lite.OpsSet.TFLITE_BUILTINS_INT8]
converter.inference_input_type  = tf.int8
converter.inference_output_type = tf.int8
tflite_model = converter.convert()

Discussion

The results demonstrate that TinyML-based elephant detection on an ESP32 is technically feasible. The 91.4% validation accuracy is sufficient for a trigger system — the primary function of which is to initiate a more detailed response rather than to replace human decision-making.

The false positive rate of 5.8% represents the main practical limitation. False positives in this system trigger unnecessary alerts, which — if too frequent — risk alert fatigue among farmers and reduced trust in the system. Applying a confidence threshold (only triggering if model output confidence > 85%) reduced the false positive rate to 2.1% in testing, at the cost of a slight increase in false negatives.

The 1.4-second inference time is acceptable for this application, as the PIR sensor provides approximately 3–5 seconds of advance warning before an elephant reaches the fence. Future work should explore the ESP32-S3 with its Xtensa LX7 processor and SIMD extensions, which preliminary benchmarks suggest could reduce inference time to under 600ms for this model.

Conclusion

This research demonstrates that a lightweight CNN achieving 91.4% elephant detection accuracy can be successfully deployed on an ESP32 microcontroller within its memory constraints, using INT8 post-training quantisation. The system provides real-time, cloud-independent inference at the edge — a critical requirement for remote wildlife monitoring deployments.

The primary contribution is a validated methodology for TinyML model design, quantisation, and ESP32 deployment for binary wildlife classification tasks. The quantisation pipeline, representative dataset calibration approach, and accuracy-versus- memory tradeoff analysis presented here provide a practical reference for future embedded AI wildlife monitoring projects.
