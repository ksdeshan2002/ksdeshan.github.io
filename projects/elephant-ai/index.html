Project Overview

Within the E-LeFence system, the fence tilt sensor and voltage unit can tell you a fence has moved or gone dark — but not whether it was an elephant, a fallen branch, or a passing animal. That identification step is handled by this module: a CNN-based image classifier trained to give a binary elephant / not-elephant output, running directly on an ESP32-S3 microcontroller so identification happens on-device, without needing a constant connection to the cloud.

When motion is detected near the fence, a camera captures an image, the model classifies it, and — only if both the AI model and the fence's gyroscope sensor trigger together — the system escalates to the alert pipeline. This two-signal requirement is deliberately designed to cut down on false alarms from smaller animals or routine fence vibration.

Why TinyML?

Running inference on the microcontroller itself avoids relying on continuous internet access, which is unreliable in most elephant habitats, and keeps the per-unit hardware cost low enough to deploy across long stretches of fence — something that isn't realistic with heavier edge hardware like a Raspberry Pi or Jetson Nano.

Why On-Device AI

  • Manually reviewing camera trap footage doesn't scale across a long fence line and can't provide real-time alerts.
  • Cloud-based image analysis needs continuous connectivity, which most rural elephant corridors don't have.
  • Existing fence breach sensors (voltage drop, tilt, motion) can't on their own distinguish an elephant from a fallen branch or a smaller animal — image-based confirmation is needed to cut false positives.
  • Powerful edge AI boards are too expensive and power-hungry to deploy at the density this problem needs.

Objectives

  • Train a CNN capable of correctly classifying elephant presence in captured images.
  • Keep the model small enough to run within the ESP32-S3's memory budget.
  • Deploy the trained model on-device so classification happens without a cloud round-trip.
  • Interface with an OV2640 camera module, including a 950nm IR array for night capture.
  • Feed a confirmed elephant classification into the fence-tilt cross-check before triggering an alert.

Model Pipeline

Data Collection

The team is currently building a custom dataset of elephant images, captured and resized to either 64×64 or 96×96 pixels — small enough to be compatible with the ESP32's limited RAM while still preserving enough detail for classification.

Model Architecture

The model is a compact CNN made up of several convolutional layers, designed to output a simple binary classification — elephant, or not — from each captured image.

Training

Training is done using TensorFlow. To improve accuracy over time, images captured in the field are periodically logged locally and folded back into the training set, with the model re-trained and then evaluated against a held-out set it has never seen before.

On-Device Inference

Once trained, the model runs on the ESP32-S3 UNO Development Board (N16R8 / MD0821). Image capture is handled by a dedicated ESP-CAM unit, which passes frames to the main ESP32 for classification. Only when the AI model and the gyroscopic tilt sensor are triggered simultaneously does the device initiate an HTTP request to the backend, which is what ultimately fires the alert.

Model Design

Dataset Split

The custom elephant image dataset — resized and grayscaled — is split 80% for training and 20% for testing, following standard practice for evaluating classifier generalisation.

Planned Evaluation Metrics

The model will be evaluated using the standard classification metrics below, based on true positives (TP), false positives (FP), false negatives (FN), and correct predictions (CP):

  • Accuracy = Correct Predictions / Total Predictions
  • Precision = TP / (TP + FP)
  • Recall = TP / (TP + FN)
  • F1-Score = 2 × (Precision × Recall) / (Precision + Recall)

As data collection and training are still in progress, final accuracy figures aren't available yet — this section will be updated once the model has been evaluated against the held-out test set.

Deployment on ESP32

Planned Pipeline

  1. Collect and label elephant / non-elephant images, resized to 64×64 or 96×96 pixels
  2. Train the CNN model in TensorFlow
  3. Evaluate on a held-out test split using accuracy, precision, recall, and F1-score
  4. Deploy the trained model onto the ESP32-S3 UNO Development Board (N16R8 / MD0821)
  5. Trigger classification from camera captures forwarded by the ESP-CAM unit

A binary classification result from this model, combined with a simultaneous trigger from the fence's gyroscope-based tilt sensor, is what the system treats as a confirmed elephant breach — rather than acting on either signal alone.

Hardware Setup

Component Purpose
ESP32-S3 UNO Development Board N16R8 (MD0821) Runs the trained AI model
ESP32-CAM board Core microcontroller for image capture, forwards frames for classification
OV2640 Camera Module (850nm, noIR) Captures images of the moving object, including at night
IR Light Array (950nm) Switchable night-time illumination for the camera
PIR Sensor Triggers image capture on motion detection to save power

Evaluation Plan

Because field testing is limited by available resources, the team plans to evaluate the AI model most rigorously — since it's the component the rest of the alert chain depends on — using the accuracy, precision, recall, and F1-score metrics described above, run repeatedly as the dataset grows. Camera and lighting hardware will be separately validated for image clarity across different lighting and weather conditions before the model is tested against real captured footage.

Next Steps

  • Finish collecting and labelling a larger elephant image dataset for training.
  • Complete initial training and measure accuracy, precision, recall, and F1-score on the held-out test split.
  • Confirm the model fits comfortably within the ESP32-S3's RAM and Flash budget at runtime.
  • Integrate the classification output with the gyroscope-based fence tilt trigger to confirm end-to-end breach detection.
  • Test night-time detection performance using the IR light array.
